# Adithyan Biju Portfolio

A responsive static portfolio for Adithyan Biju, built with plain HTML, CSS, and JavaScript.

## Local preview

Open `index.html` directly in a browser, or serve this folder with any static file server. The page, navigation, project links, and responsive layout work locally. Netlify form delivery requires a deployed site.

## Netlify form setup

1. Deploy this folder to Netlify.
2. Confirm the `contact` form appears under **Forms** in the Netlify dashboard.
3. Add an email notification for the `contact` form and forward submissions to `adithyanbiju07@gmail.com`.
4. Submit a real test message and confirm it reaches the inbox.

The form includes Netlify's required `data-netlify` attribute, a honeypot field, browser validation, and a redirect to `thank-you.html` after a successful submission.
